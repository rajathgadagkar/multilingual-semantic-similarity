Two-Stage Hybrid Retrieval & Re-Ranking Pipeline

Designed for local-first CPU deployment (< 3s latency) without sacrificing token-level semantic precision.

Stage 0 • Offline Indexing

768-d FAQ Embeddings

All language FAQ questions are encoded once at startup with paraphrase-multilingual-mpnet-base-v2 and L2-normalized.

Stage 1 • Fast Recall

Bi-Encoder Retrieval

Encodes the incoming query once and retrieves the Top-20 semantic candidates via cosine similarity in milliseconds.

Stage 2 • Precision

XLM-RoBERTa Re-Ranker

Jointly scores each [CLS] query [SEP] FAQ candidate pair with full cross-attention to select the most accurate answer.

Stage 3 • Delivery

FastAPI + Express + React

Serves ranked answers, cosine similarity, cross-encoder score, and latency to a responsive multilingual web client.
